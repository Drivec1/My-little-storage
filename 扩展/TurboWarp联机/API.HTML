📖 API 接口手册

IP 检测

快速获取请求者的 IP 地址。

功能 方法 URL 格式 示例 响应
获取 IP GET /ping/项目ID GET /ping/myproject {"projectId":"myproject","ip":"192.168.1.5"}

💡 项目ID 仅用于日志区分，可任意填写。接口不受服务暂停影响。

变量操作

支持 /git 或 /var 前缀。

功能 方法 URL 格式 示例
读取变量 GET /git/项目ID/变量名 GET /git/myproject/金币
设置变量（路径传值） POST /git/项目ID/变量名/新值 POST /git/myproject/金币/200
设置变量（Body 传值） POST /git/项目ID/变量名 POST /git/myproject/金币
Body: 200 或 {"value":200}
变量增量 POST /git/项目ID/变量名/increment POST /git/myproject/金币/increment
Body: 10 （正数增加，负数减少）

💡 数字自动存储为数字类型，字符串保持原样。

列表操作

使用 /list 前缀。

功能 方法 URL 格式 示例
创建列表 POST /list/项目ID/列表名/create POST /list/myproject/玩家/create
读取列表 GET /list/项目ID/列表名 GET /list/myproject/玩家
追加项（路径传值） POST /list/项目ID/列表名/值 POST /list/myproject/玩家/小明
追加项（Body 传值） POST /list/项目ID/列表名 POST /list/myproject/玩家
Body: 小明
替换第 N 项（路径传值） PUT /list/项目ID/列表名/索引/新值 PUT /list/myproject/玩家/2/小红
替换第 N 项（Body 传值） PUT /list/项目ID/列表名/索引 PUT /list/myproject/玩家/2
Body: 小红
删除第 N 项 DELETE /list/项目ID/列表名/索引 DELETE /list/myproject/玩家/2
清空列表 DELETE /list/项目ID/列表名 DELETE /list/myproject/玩家

💡 列表索引从 1 开始。

其他信息

  • 所有接口均支持 CORS，可在 TurboWarp 中直接调用。
  • 服务器地址：http://你的IP:端口（局域网或公网）。
  • 管理面板：/admin （可设置密码、黑名单、监控客户端）。
  • 终端命令：/log 导出日志，/stop 暂停服务，/open 恢复服务，/setting 端口 动态改端口。
  • 变量名、列表名、项目ID 均支持中文。
⚠️ 路径传值时，若值包含特殊字符（如斜杠 / 或空格），请进行 URL 编码（例如 %2F 表示 /）。
